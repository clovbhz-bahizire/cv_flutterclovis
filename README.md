# CV Flutter — Clovis Rudahindwa Bahizire

Application mobile Flutter de présentation du CV, de la famille et des coordonnées.

## Fonctionnalités
- Connexion avec identifiant et mot de passe masqué
- Page d'accueil présentant le profil et le CV
- Page Famille avec les parents
- Page Contact avec numéro de téléphone cliquable
- Navigation par menu latéral (Drawer) et barre de navigation inférieure

## Lancer le projet
1. Installer Flutter et vérifier l'installation avec `flutter doctor`.
2. Ouvrir un terminal dans le dossier `cv_flutter_clovis`.
3. Exécuter :
   ```bash
   flutter pub get
   flutter run
   ```
